# Variation Draft — 기관·지점·처리 방식

## 1. 목적

공식 Source에 나타난 기관, 특정 지점, 처리 채널과 수령 방식의 차이를 기존 Process Task에 연결한다. 방식의 존재와 공통 적용 조건을 분리하고, 특정 기관·지점의 사례를 전체 기관 Rule로 일반화하지 않는다.

## 9. Input 차이

- 방문·제출·수령 Task의 기존 Input만 사용한다.
- 기관·지점·채널별 추가 Input은 직접 Source가 있는 지점 추가 요청 서류 외에는 확인되지 않아 `UNKNOWN`이다.
- 대리·제3자 수령의 위임·신분 자료를 추정하지 않는다.

## 10. 문서 차이

- 반포역지점의 추가 요청 서류 확인 단계는 존재하지만 상세 목록과 다른 지점 적용 여부는 미확정이다.
- 기관 유형별 공통 제출 문서와 채널별 양식 차이는 `UNKNOWN`이다.
- 특정 지점 문서를 전체 은행 필수서류로 일반화하지 않는다.

### 반포역지점 CASE_ONLY

- 보완서류 4종, 카카오톡·전화 요청, 3~5일 처리기간과 특정 서류 수량은 `N-05-07`의 단일 조합·특정 지점 CASE 참고다.
- 독립 사례 검증이 아니며 다른 지점 또는 전체 은행 Rule로 승격하지 않는다.
- 농협과 농협 외 구분은 SIC-06 결정에 따라 `KEEP_UNKNOWN`이며 신규 Variation Rule을 만들지 않는다.

## 11. Decision 차이

- 계좌개설의 제출 방식 판단 Task와 고유번호증 제3자 수령 판단 지점은 존재한다.
- 방문·우편·퀵·이메일·팩스본의 공통 선택 조건은 `UNKNOWN`이다.
- 직접·대리·제3자·전자·실물 수령의 선택 우선순위와 판단 주체는 `UNKNOWN`이다.

## 12. Actor 차이

- 각 Process의 기존 Actor만 유지한다.
- 기관 유형에 따라 내부 책임자가 달라진다는 근거는 없어 새 RACI를 배정하지 않는다.
- 대리·제3자 수령자와 기타 외부기관 Actor는 `UNKNOWN`이다.

## 13. 제출·전달 차이

- Source가 직접 명시한 방문·우체국 접수·은행 전달·특정 지점 실물 제출만 해당 Task에 연결한다.
- 퀵·이메일·팩스본의 채널 존재는 해당 Task에서 `PROVISIONAL`이며 공통 적용 조건과 수신 확인 기준은 `UNKNOWN`이다.
- 방문 기록만으로 모든 동일 기관 업무를 방문 필수로 확정하지 않는다.

## 14. Output·수령 차이

- 접수증, 영수증·발송 결과물, 증명서·확인증과 실물 결과는 해당 기존 Task의 Output으로만 유지한다.
- 실물 수령과 이후 전달·보관 완료는 별도 상태다.
- 스캔본·팩스본 수령 옵션은 `PROVISIONAL`이고 후속 원본 수령·보관 Actor와 완료조건은 `UNKNOWN`이다.
- 대리·제3자 수령 증빙과 공통 수신 기준은 `UNKNOWN`이다.

## 15. 완료조건 차이

- 기존 Task의 관찰 가능한 완료조건을 그대로 사용한다.
- 특정 기관·지점·채널만의 추가 완료조건은 확인된 수신·수령 결과 외에는 만들지 않는다.
- 전자 수령, 대리·제3자 수령과 실물 최종 보관의 공통 완료조건은 `UNKNOWN`이다.

## 16. 보완·Exception 차이

- 기관 추가요구와 재방문·재제출 분기의 존재는 관련 Process에 유지한다.
- 기관·지점·채널별 감지 조건, 대응 Actor와 복귀 Task의 공통 차이는 확인되지 않아 `UNKNOWN` 또는 기존 Process 상태를 유지한다.
- 계좌해지 방문 필수 여부와 결과물 표준은 `GAP-09`의 `PROVISIONAL` 상태를 유지한다.

## 17. 적용·제외 Task

- 기관·지점·처리·수령 방식 때문에 새로 ADD하거나 EXCLUDE하는 Task는 0건이다.
- 직접 Source가 명시한 기존 Task에 채널·기관 속성만 연결한다.
- Source 없는 방식 후보를 기존 Main Flow에 추가하지 않는다.

## 18. UNKNOWN

- 기타 외부기관의 유형·역할·적용 Task
- 기관·지점별 공통 제출서류와 처리기한
- 방문·우편·퀵·메일·팩스의 선택 기준과 수신 확인 기준
- 대리·제3자 수령의 위임·신분·추가서류 요건
- 전자 수령 시스템, 증빙과 완료조건
- 직접 수령과 실물 후속 전달·보관의 공통 적용 기준

## 19. 인터뷰·CASE 검증 필요항목
