## 주 Journey — 지원팀 담당자

```
요청함
  요청 3건 중 하나 선택
  → 이 요청이 막혔는가? 누가 잡고 있는가?
      │
      ▼
업무 실행
  내가 Actor인 Task 확인
  → 다음 Action이 무엇인가?
  → Blocker가 있는가?
  → Evidence가 부족한가?          ← 질문 6 (미검증 구간)
  → 사람 확인 질문에 답할 수 있는가?
      │
      ├─ 막혀 있음 → 12. 중단. Blocker 해소 대기
      │
      ▼ 전부 처리됨
반영 검토
  생성 예정 Request 1건 / Task N건
  → Blocking Gap이 몇 개인가?
  → 0개면 승인 요청, 1개 이상이면 무엇을 먼저 확인해야 하는가
      │
      ▼ (승인자)
실행 결과  [이번 Pilot: Placeholder]
  실제 생성 Record
  → Expected–Actual
  → 재실행 시 중복 0인가?          ← 질문 10 (미검증 구간)
```

## 이탈·중단 지점

| 지점 | 조건 | 화면이 보여줘야 하는 것 |
|---|---|---|
| 4 → 12 | Actor가 외부(세무서·은행·GP) | 외부 대기 상태와 대기 시작 시점 |
| 5 → 12 | Evidence MISSING | **무엇이 없는지, 누가 가져와야 하는지** |
| 6 → 12 | 사람 확인 미응답 | 질문 원문과 응답 주체 |
| 7 → 중단 | Blocking Gap ≥ 1 | Gap별 해소 조건과 담당 |
| 8 → 반려 | 승인자 판단 | 반려 사유 기록 위치 |

## 현재 3개 Scenario의 실제 경로

| Request | Scenario | 경로 | 종착 |
|---|---|---|---|
| REQ-DEMO-001 | SINGLE-P03-02 | 1→2→3→4→5→6 | **중단** (날인본 원본 미확보) |
| REQ-DEMO-002 | SINGLE-P03-01 | 1→2→3→4→5→7 | 완료 후보 (완료 아님) |
| REQ-DEMO-003 | COMPOSITE-01 | 1→2→3→4(×3 Task) | P03·P04 진행 / P07 중단 |

**세 건 모두 7단계에서 Blocking Gap에 걸린다.** 조합 연결 대상 없음 + 중복 방지 기준 미확정.
따라서 Pilot 시연은 "막힌 이유를 이해시키는 것"이 핵심이지 "끝까지 통과시키는 것"이 아니다.
