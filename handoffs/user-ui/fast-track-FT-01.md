# FT-01 (1차 조합 예정 등록 Form 정리) — 사용자 UI 조치

대상: `TO DO LIST (FUND)` → `조합 결성 예정 등록`

5분 절차:

1. Form 편집 화면을 연다.
2. `작성자` 질문을 Form에서 숨긴다. Property는 삭제하지 않는다.
3. `요청사항`, `업무담당자`, `구분`, `업무분류`를 Required로 설정한다.
4. `조합명 또는 제목`, `우선 순위`, `검토/결과`는 Optional로 둔다.
5. Form 제목·설명은 현재 값을 유지한다.
6. 기존 View·Filter·Template은 변경하지 않는다.

확인: 질문 7개, 필수 4개.
