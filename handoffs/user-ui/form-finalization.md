# Form Finalization — 정상준 UI 절차

## 1차 Form: 조합 결성 예정 등록

1. `TO DO LIST (FUND)`에서 `조합 결성 예정 등록` Form을 연다.
2. `작성자` 질문을 Form에서 숨긴다. Property는 삭제하지 않는다.
3. 질문 표시명을 다음처럼 정리한다.
   - 요청사항 → 조합명 또는 임시 조합명
   - 업무담당자 → 담당 관리역
   - 조합명 또는 제목 → 기존 조합 Record
   - 우선 순위 → 긴급 가능성
   - 검토/결과 → 특이사항
4. 필수: 조합명 또는 임시 조합명, 담당 관리역, 구분, 업무분류.
5. 선택: 기존 조합 Record, 긴급 가능성, 특이사항.
6. 최종 질문 수가 7개인지 확인한다.

## 2차 Form: 지원팀 행정업무 요청

대상: https://app.notion.com/p/c60e9bc03a214735be082ed54905970d

1. 기존 Form을 열고 새 Form은 만들지 않는다.
2. 기존 Property만 사용해 다음 9개 질문을 구성한다.
   - 요청명 → 요청 제목 — 필수
   - 관련 조합 — 필수
   - 요청 업무 유형 → 요청 업무 — 필수
   - 담당 관리역 → 요청 관리역 — 필수
   - 목표일 → 목표 완료일 — 선택
   - 실물서류 전달 여부 → 선택
   - 원본 폴더 → 원본 폴더·관련 링크 — 선택
   - 요청 내용 → 요청사항 — 필수
   - 특이사항 — 선택
3. 요청일, 요청 상태, 요청자, 관련 Task는 Form에서 숨긴다. Property는 삭제하지 않는다.
