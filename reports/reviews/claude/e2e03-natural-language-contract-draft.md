## 1. Contract 목적

이 문서는 "사용자가 어떤 언어로 말하든, 어떤 인터페이스(Claude Code Skill·Codex 명령·Slack)로 들어오든 동일한 규칙으로 정보를 추출·질문·검증·기록한다"는 단일 계약을 정의한다. 인터페이스별 UI·구현은 정의하지 않는다(9절은 Slack 후보만 개념적으로 나열).

## 2. 공통 Interaction Lifecycle

```
자연어 요청 → 업무·FUND 식별 → 중복 확인 → 정보 추출 → 누락 질문
→ Preview → 명시 승인 → Commit → 재조회 → 상태 응답
```

- WS1-01 실행표준의 Preview-Approval-Commit-Verify 흐름(7절)과 동일하며 신규 단계를 추가하지 않는다.
- 재조회(Commit 후 즉시 Actual 값을 다시 읽어 Expected와 비교)는 CI6에서 Expected–Actual 불일치 0건으로 검증된 절차를 그대로 계약화한 것이다.

## 4. FUND 식별 Contract

| 상황 | 처리 | 검증 상태 |
|---|---|---|
| 정확히 1건 매칭 | 진행 | 검증됨 |
| 0건 | `BLOCK_AND_ASK`, Write 0 | 검증됨(CI2 recheck) |
