# Manual Pilot Readiness

판정: `READY_WITH_USER_UI_FIX`

## 충족

- 1차 Form 또는 기존 DB 직접 등록 사용 가능
- Request Record 생성 가능
- FUND Relation 저장 가능
- Task 6건 생성 및 Request Relation 가능
- Request·Task 상태 추적 가능
- Person, Actor, Next Action, Blocker, 완료조건, 증빙 저장 가능
- 완료 흐름 시연 완료

## Pilot 전 필수 UI 수정

- 2차 Form 질문 10개 구성
- `관련 조합`, `요청명`, `요청 업무 유형`, `요청자`, `담당 관리역`, `요청 내용` Required 설정
- Task `관련 조합` Rollup 표시 확인

## 비차단 Backlog

- 1차 Form 문항을 8개에서 목표 7개로 정리
- 1차 Form Respondent·공유범위 최종 확인

실제 운영 Pilot은 GPT와 사용자 승인 전 시작하지 않는다.
