# CASE-02 사용자 인터뷰 반영 기록

## 작업 범위

- `cases/case-02-humanvision.md`의 미확정 기본정보와 실제 진행 결과 갱신
- 안전계좌 전용 절차와 서류 분기 추가
- CASE-01 비교 및 규칙 판정 갱신
- 온라인팩스 알림 부재를 운영 병목으로 기록
- `tasks/active.md`의 CASE-02 완료 상태와 CASE-03 다음 행동 반영
- CASE-01 및 `rules/common.md`는 수정하지 않음
- Notion MCP 연결 및 Notion 수정은 수행하지 않음

## 확인 사실 반영

- GP 유형을 개인 GP, 공동GP를 없음으로 확정했다.
- 은행·지점을 농협은행 강남금융센터, 계좌유형을 안전계좌로 확정했다.
- 안전계좌 업무이므로 강남금융센터에서 진행한 것으로 기록했다.
- 개인투자조합은 해당 조합 승인공문과 결성계획서를 사용하는 것으로 기록했다.
- 민법상조합의 공통 법적 근거자료 및 사업계획서 사용과 구분했다.
- 유형별 계획서류 차이는 CASE-03 검증 전까지 조건부 규칙 후보로 유지했다.
- 계좌개설 실물서류 제출, 합본 PDF의 성격, 계좌개설 완료, 통장사본 수령을 확인 완료로 변경했다.
- 계좌개설 보완이 없었음을 기록했다.
- 실물 통장은 추후 방문 수령하는 후속 업무로 분리했다.

## 안전계좌 분기

- 인터넷뱅킹은 미사용으로 기록했다.
- OTP는 미완료가 아니라 `해당 없음`으로 기록했다.
- 전자금융 이체한도 추가 약정서는 제외 서류로 기록했다.
- 금융거래정보제공 동의서(투자조합 자금관리 API)를 추가 서류로 기록했다.
- 투자조합 실시간 투자이체 및 입금이체 서비스 이용신청서를 추가 서류로 기록했다.
- 미라파트너스가 인터넷뱅킹 업무를 대체하고 담당 관리역이 주요 업무를 수행하는 역할 구조를 반영했다.

## 역할·완료 기준

- 최초 요청 시 날인본을 전달받은 사실을 반영했다.
- 잔액증명서 관련 위임장과 잔액증명서 신청서를 전달받은 사실을 반영했다.
- 공용 온라인팩스 확인 후 파일명 변경, 조합 폴더 저장, 관리역 공유 순서를 기록했다.
- 스캔본 수령·저장·관리역 공유를 업무 완료 기준으로 명시했다.
- 실물 통장 수령은 업무 완료 이후의 후속 완수 항목으로 남겼다.

## 운영 병목 및 자동화 후보

- 공용 온라인팩스에 별도 수신 알림이 없어 지원팀 확인이 불특정 시점에 이뤄지는 병목을 기록했다.
- Pilot에서 정기 확인 주기, 확인 담당자, 미확인 건 추적 또는 수신 알림 자동화를 검토하도록 제안했다.

## 남은 확인 사항

- 각 업무의 정확한 제출·수령 일자
- 승인공문의 조합 폴더 내 정확한 경로
- 실물 통장의 실제 수령일과 후속 완수 여부
- CASE-01의 일부 비교정보
- CASE-03을 통한 조합유형별 계획서류 차이 검증
