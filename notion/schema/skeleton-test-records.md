# Fast Skeleton 테스트 Record 명세

## 데이터 원칙

- 가상 정보만 사용한다.
- 실제 조합명, 개인 이름, 연락처, 계좌정보, 인증정보를 사용하지 않는다.
- Drive 경로는 `TEST_PATH_ONLY`로 기록한다.
- 테스트 완료 후 보관 또는 삭제 여부를 사용자가 확인한다.

## 기대 연결 결과

- 업무 DB `관련 Task`에 9건이 표시된다.
- Task DB 9건의 `상위 업무`가 동일한 테스트 업무를 가리킨다.
- 진행 중 View에는 업무 1건과 Task 1건이 보인다.
- P08 Task는 초기 `제외` 상태이며 보완 발생 시 생성·활성화 방식은 P3에서 결정한다.
- Task 4와 8의 집약이 사용자에게 과도하거나 부족한지는 S1 관찰 항목으로 기록한다.
