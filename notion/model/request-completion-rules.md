# 업무요청 완료 규칙

## Pilot A 권장안

**필수 Task 완료 + 선택·조건부 Task 처분 + 결과 전달 + Human 최종 확인**을 모두 만족할 때 요청을 완료한다.

지원팀 내부 처리 종료와 요청자 확인을 Task·Approval로 분리해 추적하되 요청 Status는 하나만 사용한다. 선택 Task가 남아 있어도 `제외`가 아니라 `TS-CANCEL`과 승인된 제외 사유가 기록되면 완료 Gate에서 제외할 수 있다.

## 완료 Gate

| Gate | 조건 | 필수 기록 |
|---|---|---|
| RC-01 | 요청 유형별 필수 Task가 모두 `TS-DONE` | Task 상태 |
| RC-02 | 선택·조건부 Task가 완료, 취소 승인 또는 미발생으로 처분됨 | 처분 사유 |
| RC-03 | 각 필수 Task 완료조건과 Evidence가 충족됨 | Evidence ID·경로·확인자 |
| RC-04 | 결과물 또는 완료 결과가 요청자·관리역에게 전달됨 | EV-DELIVERY |
| RC-05 | HA-08 요청 완료 승인이 기록됨 | 승인자·승인일 |
| RC-06 | 요청 완료일과 완료자가 기록됨 | EV-COMPLETE |

## 업무 유형별 최소 완료 범위

| 요청 유형 | 필수 범위 | 선택·조건부 범위 | 최소 Evidence |
|---|---|---|---|
| 명판·인감 | 사양 확인, 제작 요청, 수령·검수 | 재제작·추가 제작 | EV-PHYSICAL, EV-COMPLETE |
| 고유번호증 신청 | 서류 준비·검수, 세무서 접수, 결과 수령·저장·전달 | 현장 보완 | EV-PACKAGE, EV-RECEIPT, EV-RESULT, EV-SCAN, EV-DELIVERY |
| 보안카드·홈택스 | 가입·카드 처리, 결과 저장 | 재시도·추가 확인 | EV-RESULT 또는 처리 화면 메타데이터, EV-COMPLETE |
| 계좌개설 | 유형 확인, 서류 준비·검수, 은행 전달, 결과 수령·저장·공유 | 통장·OTP 후속, P08 보완 | EV-PACKAGE, EV-RECEIPT 또는 EV-RESPONSE, EV-RESULT, EV-DELIVERY |
| 계좌개설 보완 | 보완 원인 확인, 보완본 준비·재전달, 은행 수신·심사 재개 확인 | 재날인·기존서류 회수 | EV-RESPONSE, EV-PACKAGE, EV-SCAN |

P3에서 Process Atomic Task를 Operational Task에 매핑하기 전까지 위 범위는 Contract이며 확정 Task 목록이 아니다.

## Task 생성 Contract

| 요청 업무 유형 | 생성 조건 | 필수 Task 범주 | 선택 Task | 조건부 Task | 순서·선행 | 기본 Actor | Human Approval |
|---|---|---|---|---|---|---|---|
| 명판·인감 | 제작 요청 접수 | 사양 확인 → 제작 요청 → 수령·검수 | 전달 | 재제작 | 앞 단계 완료 | 지원팀 | 사양·최종 검수 |
| 고유번호증 신청 | 착수 Input 검수 통과 | 서류 준비 → 검수 → 접수 → 결과 수령·저장 | 결과 전달 분리 | 현장 보완 | UN 흐름 | 지원팀 | 기본정보·서류·전달 |
| 보안카드·홈택스 | 고유번호증 등 선행 Input 확보 | 홈택스 가입 → 보안카드 처리 → 결과 저장 | 없음 | 재시도 | P03 결과 후 | 지원팀 | 민감 입력·결과 확인 |
| 계좌개설 | 계좌 유형·은행·필수 Input 확보 | 유형 확인 → 서류 준비·검수 → 은행 전달 → 결과 확인 | 통장·OTP 후속 | P08 보완 | AO 흐름 | 지원팀 | 계좌유형·서류·전달 |
| 계좌개설 보완 | 은행 보완 요청 발생 | 요청 등록 → 원인 확인 → 보완 준비 → 재전달 → 완료 확인 | 기존서류 회수 | GP 재날인 | AS 흐름 | 지원팀 | 보완 경로·서류 |

자동 Task 생성은 구현하지 않으며 P3에서 ID, 집약, 선행관계와 예외를 확정한다.
