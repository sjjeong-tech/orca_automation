# 업무요청 상태 모델

## Canonical 원칙

- Status는 요청 전체의 수명주기를 나타낸다.
- 외부기관·GP·관리역 대기는 Task의 `대기`와 `현재 Actor`로 표현하고 요청 상태를 세분화하지 않는다.
- 상태 변경은 수동이며, 자동 전이는 별도 승인 전 금지한다.
- `완료`와 `취소`는 Terminal 상태다. 재개하려면 승인 기록과 새 요청 또는 명시적 재개 절차가 필요하다.

## 운영 제약

- `RQ-REWORK`에는 Blocker Text에 누락 항목, 요청 대상, 요청일, 목표 회신일을 기록한다.
- `RQ-ACTIVE` 중 외부 대기는 요청 Status를 바꾸지 않고 해당 Task를 `TS-WAIT`로 둔다.
- `RQ-DONE` 전환은 [업무요청 완료 규칙](request-completion-rules.md)을 따른다.
- 현재 Notion 옵션 변경은 `OPTION_CHANGE_PROPOSED`이며 AG-P2 승인 후 별도 Build TAP에서 적용한다.
