# Notion Tracker 최소 스키마

## 속성

| 속성 | 권장 형식 | 용도 |
|---|---|---|
| 조합명 | 제목 | 대상 조합 식별 |
| 업무유형 | 선택 | 세무서·은행 등 업무 구분 |
| 담당 관리역 | 사람 또는 텍스트 | 조합 담당 관리역 |
| 지원팀 담당자 | 사람 또는 텍스트 | 실행·추적 담당자 |
| 현재 단계 | 상태 | 현재 업무 상태 |
| 다음 행동 | 텍스트 | 바로 수행할 구체 행동 |
| 행동 주체 | 사람 또는 텍스트 | 다음 행동 수행자 |
| 목표일 | 날짜 | 다음 행동 또는 단계 목표일 |
| 대기 대상 | 텍스트 | 외부 대기 시 회신·처리 주체 |
| 긴급 | 체크박스 | 긴급 건 표시 |
| 보완 | 체크박스 | 보완 진행 여부 |
| 업무 완료 | 체크박스 | 본 업무 결과 수령·완료 여부 |
| 후속 완수 | 체크박스 | 실물·시스템 등 후속조치 완료 여부 |
| Drive 경로 | URL 또는 텍스트 | 실제 파일과 결과물 위치 |

## 현재 단계 상태값

1. 예정
2. 준비 중
3. 외부 대기
4. 제출 완료
5. 보완 중
6. 결과 수령
7. 후속 처리
8. 완료

`완료`는 업무 완료와 후속 완수가 모두 확인된 경우에만 사용한다. 상태 전환 규칙과 속성별 필수 입력 조건은 Pilot 전에 추가로 확정한다.
