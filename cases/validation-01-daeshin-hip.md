# VALIDATION-01 대신-HIP 우주항공 신기술투자조합 제1호

## 1. 기본정보

- 조합명: 대신-HIP 우주항공 신기술투자조합 제1호
- 조합유형: 신기술투자조합
- 계좌유형: 수탁계좌
- 문서 목적: 신기술투자조합의 세무서 업무 차이 검증
- 분류: 부분 절차 검증 사례
- 검증 상태: 진행 중

이 사례는 지원팀 사용자가 계좌개설을 직접 수행하지 않았으므로 수탁계좌 전체 E2E 사례로 사용하지 않는다.

## 2. 사용자가 실제 수행한 범위

- 고유번호증 업무
- 보안카드 업무

각 업무의 신청서류, 처리 순서, 보완, 결과물과 완료조건은 추가 확인한다.

## 3. 수행하지 않은 범위

- 수탁계좌 개설 실무
- 수탁계좌 개설 과정에서 GP와의 직접 협의
- 수탁계좌 개설 서류 준비·제출·보완·결과 수령의 E2E 수행

수탁계좌 개설은 담당 관리역이 GP와 직접 논의하고 진행했다. 따라서 확인되지 않은 계좌개설 절차를 지원팀 수행 절차로 기록하지 않는다.

## 4. 신기술투자조합 세무서 차이 검증 질문

1. 고유번호증 신청 시 민법상조합·개인투자조합과 달리 제출하거나 제외한 법적 근거자료는 무엇인가?
2. 신기술투자조합에서는 사업계획서 또는 결성계획서가 실제로 제외되었는가? 제외 근거는 무엇인가?
3. 관할 세무서, 신청 방식, 처리 순서가 CASE-01·02와 달랐는가?
4. 고유번호증 또는 보안카드 처리 중 보완 요청이 있었는가? 있었다면 다른 조합유형과 다른 내용은 무엇인가?
5. 결과물 수령·저장·관리역 공유 및 완료조건이 CASE-01·02와 달랐는가?
