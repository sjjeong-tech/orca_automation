# CASE-03 후보 탐색

## 1. 선정 목적

사용자가 고유번호증 업무부터 계좌개설 완료와 결과 공유까지 직접 수행한 사례 중 CASE-01·02에서 확인하지 못한 조건을 검증할 CASE-03을 선정한다.

우선 검증 조건은 법인 GP, 벤처투자조합, 다른 은행·지점, 계좌개설 보완 경험이다. 파일명만으로 GP 유형이나 업무 완료 여부를 확정하지 않으며, 신청서류와 결과물 증거 및 사용자 수행범위를 함께 확인한다.

## 2. 필수 선정조건

| 조건 | 필수 여부 | 확인 방법 |
|---|---|---|
| 사용자가 고유번호증부터 계좌개설까지 직접 수행 | 필수 | 사용자 확인 및 단계별 작업파일·전달 기록 대조 |
| 계좌개설 서류 준비·제출·결과 공유를 사용자가 수행 | 필수 | 사용자 인터뷰, 제출본, 결과 공유 기록 확인 |
| 계좌개설 신청서류 합본 존재 | 필수 | 조합 Drive 폴더에서 합본 원문 확인 |
| 통장사본 또는 계좌개설 결과물 존재 | 필수 | 조합 Drive 폴더에서 결과물 원문 확인 |
| 실제 계좌개설 완료조건 확인 가능 | 필수 | 결과 수령·저장·공유 및 후속조치 기록 확인 |
| 법인 GP | 우선 | 승인공문, 등기·법인 관련 근거자료 또는 사용자 확인 |
| 벤처투자조합 | 우선 | 조합명만이 아니라 승인공문 등 조합 근거자료 확인 |
| CASE-01·02와 다른 은행·지점 | 우선 | 신청서류·결과물의 기관 정보와 사용자 확인 |
| 계좌개설 보완 사례 | 우선 | 보완 요청·회신 자료 또는 사용자 확인 |
| 민감정보 비기록 | 필수 | 문서화 전 계좌번호·인증정보·개인 식별정보 제외 검토 |

## 4. 제외·부분검증 후보

| 조합명 | 제외 또는 분리 사유 | 활용 가능 범위 |
|---|---|---|
| 대신-HIP 우주항공 신기술투자조합 제1호 | 수탁계좌 개설을 담당 관리역이 GP와 직접 진행했고 지원팀 사용자는 고유번호증·보안카드만 수행 | VALIDATION-01 신기술투자조합 세무서 절차 검증 |
| 대량 반복 처리 사례 [후보 확인 필요] | 단일 사례의 E2E 조건 검증과 목적이 다름 | BATCH 후보로 분리해 반복업무 표준화·자동화 검증 |

다음 유형은 발견 시 CASE-03 후보에서 제외하거나 별도 분류한다.

- 수탁계좌 개설을 관리역이 직접 수행한 사례
- 지원팀 사용자가 고유번호증·보안카드만 수행한 부분 사례
- 대량 반복 처리 사례

## 5. 사용자 확인 질문

각 후보별 질문은 아래 3개로 제한한다.

1. 이 조합의 조합유형과 GP 유형을 어떤 근거자료로 확인할 수 있는가?
2. 사용자가 고유번호증부터 계좌개설 서류 준비·제출·결과 공유까지 직접 수행했는가? 수행하지 않은 단계가 있다면 무엇인가?
3. 신청서류 합본과 통장사본 또는 결과물은 어디에 있으며, 은행·지점·보완 여부와 실제 완료조건을 확인할 수 있는가?
