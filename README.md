# 세무서·은행 행정업무 표준화·자동화

미라파트너스 지원팀의 세무서·은행 행정업무를 사례 기반으로 분석하고, 반복 가능한 표준과 자동화 체계로 발전시키는 프로젝트입니다.

## 발전 순서

1. 사례 분석
2. 공통규칙 도출
3. Notion Tracker 설계
4. Pilot 운영
5. 자동화

## 현재 단계

- CASE-01 테일프론티어투자조합3호 분석 완료
- 분석 범위: 고유번호증, 보안카드, 홈택스, 계좌개설, 보완, 실물 후속관리
- 다음 작업: CASE-02~04 분석 및 CASE-01과의 공통점·차이점 분류

## 정보 저장 원칙

- Notion: 업무 상태, 책임, 다음 행동 관리
- Google Drive: 실제 작업파일, 제출본, 접수증, 결과물 관리
- Git: 표준규칙, 비식별 사례, Agent 작업지침 관리

민감정보와 원본 증빙은 이 저장소에 기록하지 않습니다. 확인되지 않은 내용은 사실처럼 작성하지 않고 확인 필요 항목으로 남깁니다.

## 구조

- `rules/`: 공통·조건부·기관별·예외 규칙
- `cases/`: 비식별화된 사례 분석
- `schemas/`: Tracker 등 관리 구조
- `tasks/`: 현재 작업과 다음 행동
